# Where to download the 2024 and 2025 annual reports of twelve Indonesian listed banks

Method note (applies to everything below): research date 2026-11-20. Page fetching is blocked in this environment (one attempt on www.idx.co.id failed with a DNS/allow-list error), so **nothing here was opened or downloaded**. Every URL below is copied from a web-search result (link list or result summary); none was guessed or built from a pattern. Language and file-type labels come from the search-result title, the file name, or the search summary, as stated per row. All 20 permitted searches were used.

## Key question 1: For each bank, the annual-report archive page and the direct PDF links for the 2024 and 2025 annual reports

### Takeaway
All twelve banks have an annual-report archive page on their own site, and a direct PDF link for the 2025 report was found for nine of the twelve (BBRI, BBNI, BRIS, BNGA, NISP, BNLI, BDMN, BNII, PNBN) and for the 2024 report for eleven of the twelve (all except BBNI). For Mandiri 2025, BCA 2025 and BTN 2025 only the archive page (which lists the report) was found; for BNI 2024 only the archive page.

## Key question 2: Does idx.co.id offer annual reports per company under "Laporan Keuangan dan Tahunan", and what is the URL pattern?

### Takeaway
Yes. The Indonesia Stock Exchange has a "Laporan Keuangan dan Tahunan" page under its listed-companies section, with an English twin, that lists filings per issuer code. The page address is fixed; no per-company URL (for example a ticker in the address) appeared in any result, so the company and year are chosen with on-page filters.

### Cited Findings
- Indonesian page, titled "Laporan Keuangan dan Tahunan" — [idx.co.id](https://www.idx.co.id/id/perusahaan-tercatat/laporan-keuangan-dan-tahunan)
- English page, titled "Financial Statements & Annual Report" — [idx.co.id](https://www.idx.co.id/en/listed-companies/financial-statements-and-annual-report)
- Per the search summary of that page: it shows a list per issuer code with period filters "Triwulan 1", "Triwulan 2", "Triwulan 3" and "Tahunan" (quarters 1 to 3 and annual), and each company typically has PDF, Excel and XBRL files — [idx.co.id](https://www.idx.co.id/id/perusahaan-tercatat/laporan-keuangan-dan-tahunan)
- Annual reports that companies file are stored on the exchange's site under an announcements path with a year-month folder and a hashed file name. Example seen: a listed company's "Laporan Tahunan 2024 / Annual Report 2024" filed in April 2025 — [idx.co.id StaticData example](https://www.idx.co.id/StaticData/NewsAndAnnouncement/ANNOUNCEMENTSTOCK/From_EREP/202504/76c017266a_153ef21e33.pdf)
- A different page, "Laporan Keuangan & Tahunan" under "Tentang BEI" (about the exchange), holds the exchange's own corporate annual reports, not those of listed companies — [idx.co.id tentang-bei](https://www.idx.co.id/id/tentang-bei/laporan-tahunan/)
- Listed companies must file an annual report under OJK Regulation 29/POJK.04/2016, and financial statements must be filed in XBRL format, per the exchange's disclosure rule (Kep-00015/BEI/01-2021) — [idx.co.id Peraturan I-E](https://www.idx.co.id/media/9622/peraturan_i_e_kewajiban_penyampaian_informasi.pdf)
- The exchange's own domain was not reachable from this research environment (a fetch of www.idx.co.id failed with a host-resolution error), so the page layout above rests on the search summary alone — [idx.co.id](https://www.idx.co.id/id/perusahaan-tercatat/laporan-keuangan-dan-tahunan)

### Inferences
- The exchange page is a workable fallback for the three 2025 reports with no direct link (Mandiri, BCA, BTN) and for BNI 2024: choose the issuer code (BMRI, BBCA, BBTN, BBNI), the year, and the "Tahunan" period. Annual reports there are the files the banks themselves submitted, so content should match the bank-site version, though file names are hashed and less readable.
- The hashed files on ir-bri.com (for example "cbc6f3b797_5b008e3365.pdf" in the BRI results) use the same "hash_hash.pdf" naming as the exchange's announcement files, which supports the reading that bank IR "newsroom" files are copies of exchange filings.
- Exchange-hosted files cannot be predicted from the ticker: the path contains only a year-month folder and a hash, so each file has to be located through the page filters or a search.

### Gaps
- Whether the page accepts the issuer code or year as an address parameter (a direct per-company link) was not found; the page could not be opened.
- Whether the "Tahunan" filter returns the annual report itself, the audited annual financial statements, or both in one list was not confirmed. The search summary describes PDF, Excel and XBRL files, which fits financial statements; the annual report may sit under a separate report-type selector on the same page.
- No exchange-hosted link for any of the twelve banks' 2024 or 2025 annual reports appeared in results.
- Whether the exchange site allows automated or scripted downloads was not tested.
