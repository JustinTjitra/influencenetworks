# Where to download the 2024 and 2025 annual reports of 22 Indonesian listed palm oil and media companies, plus exchange data access facts

Method note (applies to every section): 30 web searches were used (the full budget). Page fetching is blocked in this environment (one attempt on www.smart-tbk.com failed with a DNS/allow-list error and was not retried), so **no page or PDF was opened**. Every URL below appeared in a search result; the year attached to a PDF is taken from the result's title, the file name, or the search tool's snippet of the document, not from reading the file. "Not found" means the URL did not appear in a search result, not that the report does not exist.

## Palm oil companies: archive page and direct PDF links (SMAR, SIMP, LSIP, AALI, SGRO, TAPG, DSNG, BWPT, ANJT, UNSP, SSMS)

### Takeaway
A direct PDF link for the 2024 annual report was found for 9 of the 11 palm oil companies (all except BWPT and ANJT), and a 2025 report PDF for 7 (SMAR, AALI, SGRO, DSNG and ANJT with a clear title or file name; SIMP and LSIP probable but unverified). An archive (listing) page on the company's own site was found for SMAR, AALI, DSNG, BWPT and ANJT only; for the others the PDF link is the entry point.

## Public JSON endpoint behind IDX listed-company profile pages (GetCompanyProfilesDetail)

### Takeaway
The endpoint name is corroborated: an open-source scraper lists `GetCompanyProfilesDetail` among IDX endpoints and describes it as returning board, shareholders and subsidiaries. No official IDX documentation was found, and the exact response field names could not be confirmed because neither the repository nor the blog post could be opened.

### Cited Findings
- The GitHub repository nichsedge/idx-bei (Python/Node scraper for IDX market data and fundamentals) includes `GetCompanyProfilesDetail` in its endpoint list, described as covering board, shareholders and subsidiaries — [github.com/nichsedge/idx-bei](https://github.com/nichsedge/idx-bei). It is MIT-licensed according to its index entry — [ecosyste.ms](https://awesome.ecosyste.ms/projects/github.com%2Fnichsedge%2Fidx-bei).

- antonizer/IDX-Scrapper is a Python scraper that "uses API endpoints from PT Bursa Efek Indonesia on its idx.co.id website" — [github.com/antonizer/IDX-Scrapper](https://github.com/antonizer/IDX-Scrapper). The snippet does not name the profile call.
- Other open-source projects working against idx.co.id: [noczero/idx-fundamental-analysis](https://github.com/noczero/idx-fundamental-analysis); [fzn0x/idx](https://github.com/fzn0x/idx/wiki) (Rust CLI and MCP server); [yogiz/stock-transaction-scraper](https://github.com/yogiz/stock-transaction-scraper).

- A paid scraper on Apify sells Indonesian company profiles (name, sector, address) — [Apify](https://apify.com/scrapers_lat/indonesia-companies-scraper).

### Inferences
- The endpoint is an undocumented internal API used by the idx.co.id front end; its use by several independent scrapers and the absence of any IDX documentation in results both point that way.
- From background knowledge, not verified in this session: the response of `/primary/ListedCompany/GetCompanyProfilesDetail?KodeEmiten=XXXX&language=id-id` is a JSON object whose top-level keys include `Profiles`, `Sekretaris`, `Direktur`, `Komisaris`, `KomiteAudit`, `PemegangSaham`, `AnakPerusahaan`, `KAP` and `Dividen`; `Profiles` carries fields such as `TanggalPencatatan` (listing date). Treat these names as a lead to check against the nichsedge/idx-bei source, not as a finding.
- Also from background knowledge: idx.co.id sits behind Cloudflare bot protection and commonly returns 403 to plain HTTP clients, which is why scrapers use browser automation or browser-like TLS clients. Not verified here.
- If the endpoint works, `Profiles[].TanggalPencatatan` for SCMA would be the primary-source confirmation of the 16 July 2002 listing date.

### Gaps
- Exact request parameters and response field names are unconfirmed: page fetching is blocked, and GitHub access in this session is limited to the project's own repository, so the README and source of nichsedge/idx-bei could not be read.
- No official IDX API documentation or terms of use for this endpoint were found.
